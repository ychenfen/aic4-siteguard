# 筑安智检：施工现场安全隐患 AI 巡检与整改闭环系统

**赛道：** 人工智能+场景·建造　**赛题：** 创新应用【青创学生组】　**阶段：** 初赛

> 本文是初赛方案的简版，完整论述、实验与参考文献见 [`paper/论文.md`](paper/论文.md)（Word 版 `paper/论文.docx`）。标注“待补”的地方需要团队补充。

## 1. 背景与痛点

建筑施工是安全事故高发行业。住建部办公厅关于 2019 年房屋市政工程生产安全事故情况的通报显示，当年全国发生房屋市政工程生产安全事故 773 起、死亡 904 人，其中高处坠落占 53.69%、物体打击占 15.91%、土方基坑坍塌占 8.93%、起重机械伤害占 5.43%。大量事故的直接原因是作业人员不按规定佩戴防护用品、违规进入危险区域。

现场安全管理目前主要依靠安全员人工巡查，存在三个问题：

1. **看不全**：一个安全员要覆盖整个工地，盲区和时间空档多；工地虽然普遍装了监控，但视频基本只用于事后调阅。
2. **报不准**：现有一些 AI 识别产品逐帧报警，遮挡、远景、单帧误检导致告警刷屏，安全员很快就不再看了。
3. **管不住**：发现隐患后靠口头通知或微信群，整改有没有做、有没有复查，缺少记录，难以闭环和追责。

## 2. 方案概述

筑安智检复用工地已有的监控摄像头，不新增硬件，把“发现 → 判定 → 定级 → 派单 → 整改 → 复查”串成一条线：

| 环节 | 做法 |
|---|---|
| 发现 | YOLO 目标检测识别人员、安全帽、裸头、反光背心、烟火 |
| 关联 | 按头部/躯干区域把装备框归到具体人身上；人体过小（远景）时不做判断 |
| 跟踪 | IoU 跟踪给每个人稳定编号，同一人的违规只记一次 |
| 判定 | 规则引擎判断未戴帽、无背心、闯入危险区（多边形标定）、烟火 |
| 确认 | 双条件时序确认：持续时长 ≥ T 且命中帧占比 ≥ ρ 才确认，过滤单帧误检和零星误检 |
| 去重 | 一段连续违规只报一次，持续违规定时提醒；同一人的第二次违规不会被冷却期吞掉 |
| 定级 | 风险分 = 规则严重度 + 复合风险加分，分为重大 / 较大 / 一般 |
| 派单 | 自动生成整改通知单，写明规范依据、整改措施、整改期限 |
| 闭环 | 待整改 → 整改中 → 待复查 → 已闭环，复查不通过可退回 |

## 3. 创新点

1. **双条件时序确认**：只看持续时长时，检测器零星误检会被“中断容忍”机制串成一段假违规；加上命中占比条件后，这类误报几乎全部被过滤。仿真实验中误报比“仅时长确认”再减少 77.3%。
2. **片段级去重**：以违规片段而非固定冷却期去重，召回率比固定冷却高 4.6 个百分点。
3. **复合风险升级**：同一人同时触发多条规则（例：未戴安全帽进入塔吊回转区）时叠加风险分，自动升为重大隐患、要求立即停工。单项识别产品一般做不到这一点。
4. **规范依据数据化**：每条规则绑定 JGJ59、GB 6067.1、GB 50720 等规范的检查项与整改措施，写在 `rules.json` 中，项目可以按自己的管理规定增删，整改单直接引用。
5. **从识别走到闭环**：输出的不是一个告警框，而是可流转、可追溯的整改工单和统计看板，直接对接安全员的日常工作。
6. **可复现的量化评估**：自建带真值的工地场景仿真器和检测器误差模型，在同一输入上对比基线、消融和本文方法。
7. **轻量可落地**：核心引擎纯 Python、无第三方依赖；检测模型可替换；离线即可演示，适合边缘设备部署。

## 4. 技术路线

- **检测模型**：YOLOv8/YOLO11 系列，在公开安全帽数据集（如 SHWD）基础上，补充反光背心、烟火样本和自采工地图片微调。（待补：训练集规模、mAP 指标。）
- **关联与跟踪**：基于几何包含度的装备-人员匹配；IoU 跟踪（后续可换 ByteTrack）。
- **危险区判定**：取人体框底边中点（脚底点）做点在多边形判定，比用框中心更贴近“人站在哪里”。
- **规则引擎**：配置化规则（类型、严重度、确认时长、依据、措施）+ 全局命中占比阈值与去重参数 + 复合规则。
- **工单与看板**：工单状态机；前端演示页展示监控画面、告警流、整改单和统计。

## 5. 当前进展（初赛）

- 已完成规则引擎、人员-装备关联、跟踪、双条件确认、片段去重、复合风险升级、工单闭环，单元测试 13 项全部通过；
- 已完成仿真评估（20 个场景、3.3 小时）：与“逐帧+固定冷却”相比，误报从每小时 1685.4 次降到 65.1 次（−96.1%），告警精确率 0.403 → 0.938，召回率 0.859 → 0.962，平均确认时延 3.02 秒；
- 已完成完整参赛论文（含 6 幅图、7 张表、17 篇参考文献）；
- 已完成离线演示：30 秒塔吊区回放，触发 5 类规则，生成 5 张整改单（重大 1、较大 3、一般 1），单帧误检被过滤；
- 已完成可视化演示页（浏览器直接打开）。

## 7. 应用价值

- 安全员：从“满场跑着找”变成“看告警、跟工单”，把精力放在处理和复查上；
- 项目部：隐患数据可统计（哪类隐患多、哪个区域多、整改是否及时），用于班前教育和考核；
- 行业：可复用现有监控设施，低成本推广到中小项目。
