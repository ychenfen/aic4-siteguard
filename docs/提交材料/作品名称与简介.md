# 作品名称

筑安智检：工地隐患AI巡检与整改闭环

# 作品简介

施工现场未戴安全帽、违规进入吊装区、基坑临边滞留等隐患多靠人工巡查，监控视频多用于事后取证。已有 AI 识别多为逐帧报警，误报多，且与整改脱节。

筑安智检复用工地现有摄像头，流程为“检测—关联—跟踪—规则—决策—工单”。提出双条件时序确认，过滤零星误检；以违规片段为单位去重；未戴安全帽者进入塔吊区时升级为“重大”；告警依据 JGJ59 等规范生成整改通知单，并跟踪至闭环。

仿真评估（20 个场景、3.3 小时）显示，相比逐帧加固定冷却，误报由每小时 1685 次降至 65 次，精确率由 0.40 升至 0.94，召回率由 0.86 升至 0.96。系统为纯 Python 实现，可离线演示。
